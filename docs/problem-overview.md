# Problem
The company has a substantial body of historical research, but users currently need to navigate individual reports to find and connect relevant information.

# Pain
The value of the research is already there, but the PDF-based format limits how easily customers can interrogate the knowledge across multiple reports. Committing to a full enterprise solution before proving the concept and customer value would also require a significantly larger investment.

# Outcome
Build a working prototype where an authorised user can ask questions across a selected company's research library and receive useful, source-grounded answers. This would allow them to demonstrate and assess the concept before deciding on a larger production implementation.

# Your Mission

You’ll need to submit a concept proposal covering:

- How users can ask questions across multiple company's research reports
- How research documents can be ingested, indexed and retrieved efficiently
- How AI can generate answers grounded in the relevant research sources
- How the system can show citations, document names or page references so users can verify answers
- How access can be restricted to authorised users and selected research libraries
- Your proposed workflow, architecture and technology stack
- How you would evaluate answer quality, relevance and source accuracy
- How the prototype could demonstrate customer value before a full enterprise implementation
